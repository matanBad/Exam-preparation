Fix and unify the Lecturer Course Details flow.

Current problem:
There are currently two different outcomes when a lecturer clicks a course:

1. Lecturer Courses page → click course
2. Lecturer Dashboard → Your courses → click course

These two entry points may lead to different routes/views/components and show different content.

Required outcome:
There must be ONE unified Lecturer Course Details page.
Both entry points must open the same shared page, and that page must include the useful content that currently appears in BOTH existing outcomes.

Do not choose one page and delete the other if it causes useful content to be lost.
Instead, inspect both current outputs and merge their useful sections into one shared Lecturer Course Details page.

3. Navigation unification
==================================================

Both of these entry points must navigate to the same shared Lecturer Course Details page:

1. Lecturer Dashboard → Your courses → click course
2. Lecturer Courses page → click course

Use the same route, same component, and same data-loading logic.

Do not create:
- dashboard-specific course details page
- courses-page-specific course details page

- duplicate route logic

If the correct existing route is:

G. Course-specific analytics

Do not show global dashboard analytics inside the course page.
