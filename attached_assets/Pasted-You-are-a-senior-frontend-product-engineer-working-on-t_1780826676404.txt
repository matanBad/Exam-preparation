==================================================
MAIN UX GOAL
==================================================

Make the Student Dashboard feel like one organized, professional dashboard instead of separate disconnected sections.

The student should understand within 5 seconds:
1. What is my current learning status?
2. What should I do next?
3. Where am I weak?
4. How am I progressing?
5. How do I continue studying?

==================================================
RECOMMENDED NEW DASHBOARD STRUCTURE
==================================================

Reorganize the Student Dashboard in this exact order:

--------------------------------------------------
1. Header Area
--------------------------------------------------

At the top of the dashboard content, show:

Left side:
- Welcome, [Student Name]
- Subtitle:
  "Track your preparation progress and continue studying."

Right side:
- Practice Mode button
- Start Mock Exam button

Button rules:
- Practice Mode should navigate to the existing Practice page.
- Start Mock Exam should navigate to the existing mock exam flow.
- Keep the primary green style for Start Mock Exam.
- Keep Practice Mode as secondary/outlined button.

Do not move these actions far away from the welcome area.

--------------------------------------------------
2. Main Summary Cards Row
--------------------------------------------------

Create one clean row of exactly 5 compact summary cards:

1. Average Score
2. Readiness
3. Weak Areas
4. Recommendations
5. Learning Streak

Each card should include:
- small icon
- uppercase/small title
- main metric
- short helper text

Examples of helper text:
- Average Score: "Exams & practice"
- Readiness: "Keep practicing" or the current readiness label
- Weak Areas: "View details →"
- Recommendations: "View details →"
- Learning Streak: "Keep it up"

Important:
Move Learning Streak into this first summary row.
Do NOT keep Learning Streak as a separate large card above the rest of the dashboard.

Remove or merge the old separate “Practice” summary card if it duplicates Practice Mode / Practice Progress.
The dashboard already has a Practice Mode button and Unfinished Practice section, so a separate Practice metric card is less important.

Keep all cards equal height and visually consistent.

--------------------------------------------------
3. Continue Where You Left Off Section
--------------------------------------------------

Directly under the summary cards, add a compact section titled:

"Continue where you left off"

Inside it, show two side-by-side compact cards:

A. Unfinished Practice
B. Unfinished Exams

If unfinished practice exists:
- show course/topic/session name if available
- show progress, for example: "12 of 20 questions completed"
- show progress bar if data exists
- show Continue button

If no unfinished practice exists:
- show a clean empty state:
  "No unfinished practice"
- optional action:
  "Start Practice"

If unfinished exam exists:
- show exam/course name if available
- show progress, for example: "14 of 50 questions"
- show Continue button

If no unfinished exams exist:
- show:
  "No exams in progress"
- optional action:
  "Start Mock Exam"

Important:
Do not use full-width huge cards for empty unfinished sections.
Keep this section compact and balanced.

--------------------------------------------------
4. Analytics Row
--------------------------------------------------

Create a two-column analytics row:

Left panel:
Progress over time

Right panel:
Topic Performance

--------------------------------------------------
4A. Progress Over Time
--------------------------------------------------

Keep the existing chart if it already works.

Improve the layout:
- title: "Progress over time"
- optional filter/dropdown if already exists, such as "Last 7 days"
- clean chart spacing
- if there is no progress data, show a friendly empty state:
  "No progress data yet. Complete exams or practice sessions to see your trend."

Do not add a heavy new charting library.
If a chart library already exists, reuse it.
If no chart library exists, use the current implementation or a clean list-based trend.

--------------------------------------------------
4B. Topic Performance
--------------------------------------------------

Show a compact topic performance list.

Each row should show:
- topic or subtopic name
- course name/subtitle
- accuracy percentage if enough data exists
- status badge

Status badge examples:
- Strong
- Needs Practice
- Weak
- Not enough data

Very important:
Do NOT mark topics as “Weak” only because they have 0% and insufficient attempts.

If attempts_count is less than the minimum threshold, show:
- percentage: "—" or "Not enough data"
- badge: "Not enough data"

Only show "Weak" when the backend/analytics indicates enough attempts and weakness_level = weak.

This avoids making the student feel like they failed everything when the real issue is lack of data.

Add a small "View all" link to navigate to Weak Areas or detailed analytics if such route exists.

--------------------------------------------------
5. Courses and Recent Exams Row
--------------------------------------------------

Under the analytics row, show two or three compact panels:

A. Current Courses
B. Recent Exams
C. Milestones, if there is enough horizontal space

--------------------------------------------------
5A. Current Courses
--------------------------------------------------

Show a compact list of current courses.

Recommended:
- course code + course name
- optional progress/score if already available
- "View all" link

Keep this panel shorter and cleaner than the current version.
Do not make it overly tall.

--------------------------------------------------
5B. Recent Exams
--------------------------------------------------

Show recent exams in a compact list.

Each row:
- Exam name
- Score
- Date if available

If no exams:
- "No completed exams yet."
- optional "Start Mock Exam" action

--------------------------------------------------
5C. Milestones
--------------------------------------------------

Milestones should be a compact card, not a dominant top-level section.

Show:
- "Milestones"
- "[X] achievements unlocked"
- "View achievements →"

If no milestones:
- "No milestones yet"
- "Complete practice sessions or mock exams to unlock achievements."

Do not place Milestones above the main learning summary row.
