I am experiencing an issue in my Exam Preparation System (EPS) project.

Context from the EPS PRD:
The system uses React + Axios on the frontend, Node.js + Express REST API on the backend, and a database layer.

The PRD defines course-related APIs such as:
- GET /courses
- GET /courses/:id
- GET /courses/:id/topics
- GET /users/:id/courses

The PRD also requires:
- role-based access control
- secure session validation
- least-privilege permissions
- academic data access limited by user role and course context

Important access-rule clarification:
There is a difference between the Dashboard and the Courses Page.

Student behavior:
- In the Student Dashboard, the student should see only the courses relevant to the current academic year and semester.
- In the Courses Page, the student may see all courses that belong to the degree/program they are studying, regardless of current year or semester.

Lecturer behavior:
- In the Lecturer Dashboard, the lecturer should see only the courses they teach.
- In the Courses Page, the lecturer should also see only the courses they teach.

Admin behavior:
- Admin users may access system-level course data according to admin permissions.

Current problem:
The courses list loads correctly in Edit mode, but in Viewer / Read-Only / Published mode it returns an empty result or fails to load.

What I suspect:
- A backend authentication or authorization middleware may be blocking GET requests for courses when the user is not an editor.
- The GET courses route may incorrectly require editor/admin permissions.
- Viewer mode may be using the wrong filtering logic, for example Dashboard filtering instead of Courses Page filtering.
- The frontend Axios/fetch request may behave differently in Viewer mode, for example wrong base URL, missing credentials/cookies, or incorrect environment variables.
- The database access logic may be doing a write operation during a read request, for example initializing data or calling db.set during GET, which may fail in Viewer mode.
- Replit / published environment permissions may differ from workspace Edit mode.
