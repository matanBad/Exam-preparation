==================================================
ENGAGEMENT SERVICE REQUIREMENTS
==================================================

Create a reusable Engagement Service.

Recommended functions:

1. handlePracticeCompleted(userId, practiceSessionId)
Called after a practice session is completed.

Responsibilities:
- update learning streak
- check practice-related milestones
- possibly create milestone notification
- possibly clear or update study reminder conditions

2. handleExamSubmitted(userId, examId)
Called after a mock exam is submitted.

Responsibilities:
- update learning streak
- check exam-related milestones
- create milestone notification if relevant

3. handleAnalyticsUpdated(userId)
Called after Weak Area / Performance Summary recalculation.

Responsibilities:
- detect new weak areas
- create weak_area_alert notifications for high-priority weak areas
- create recommendation_alert notifications for new high-priority recommendations

4. updateLearningStreak(userId, activityDate)
Responsibilities:
- If no streak exists, create one.
- If activityDate equals last_activity_date, do not increment again.
- If activityDate is exactly one calendar day after last_activity_date, increment current_streak.
- If activityDate is more than one day after last_activity_date, reset current_streak to 1.
- Update longest_streak if current_streak exceeds longest_streak.
- Update last_activity_date.
- Create streak_update notification only when meaningful milestones are reached, such as 3-day streak or 7-day streak.
- Do not create a notification every day unless there is a milestone.

5. checkMilestones(userId)
Responsibilities:
Check real activity data and create milestones once.

Milestone rules:
- first_practice_completed:
  when completed practice sessions count >= 1
- five_practice_sessions:
  when completed practice sessions count >= 5
- ten_practice_sessions:
  when completed practice sessions count >= 10
- first_mock_exam_completed:
  when submitted mock exams count >= 1
- first_exam_above_80:
  when any submitted mock exam score >= 80
- three_day_streak:
  when current_streak >= 3
- seven_day_streak:
  when current_streak >= 7
- first_recommendation_completed:
  when completed recommendations count >= 1
- first_weak_area_improved:
  if performance_summary shows a topic improved from weak to needs_practice/strong, only if previous state is available.
  If previous state is not tracked, skip this milestone for now instead of faking it.

6. createNotificationIfNotExists(userId, type, milestoneKeyOrDedupKey, title, message, actionUrl)
Responsibilities:
- prevent duplicate notifications for the same event.
- create notification with status = unread.
- return existing notification if already created.

STREAK REQUIREMENTS
==================================================

Track learning streaks for students.

- completed practice session
- submitted mock exam

- viewing a course
- viewing a recommendation

Streak calculation:

  current_streak = 1

  current_streak = 1
- longest_streak = max(longest_streak, current_streak)
