## 🎯 Core Curriculums & Engineering Modules

The codebase and documentation are structured across several foundational domains in software engineering:

### ⚙️ 1. Systems Programming & Operating Systems
Focuses on low-level development, POSIX compliance, and Linux architecture.
* **Process Management:** Deterministic workflow isolation using `fork()`, exec families, and lifecycle management.
* **Inter-Process Communication (IPC):** Unidirectional and bidirectional data flows via anonymous `pipes`, named pipes (FIFOs), and high-throughput `shared memory` segments.
* **Concurrency & Synchronization:** Thread safety, race-condition mitigation, and critical section protection utilizing POSIX `semaphores` and mutexes.

### 🧮 2. Numerical Analysis & Scientific Computing
Algorithmic implementations dedicated to mathematical precision and error analysis.
* **Numerical Differentiation:** High-order accuracy approximations using techniques like **Richardson Extrapolation** and complex-step differentiation methodologies.
* **Root Finding & Optimization:** Iterative approximation algorithms optimized for convergence rate and computational efficiency.

### 🔐 3. Cryptography & Cybersecurity Protocols
Practical application and simulation of modern cryptographic primitives.
* **Key Exchange:** Prototyping and analysis of secure password-authenticated key exchange mechanisms (e.g., **CPACE** protocol).
* **Data Integrity:** Hands-on implementations of symmetrical/asymmetrical encryption and cryptographic hashing frameworks.

### 📐 4. Advanced Algorithms & Object-Oriented Design
Solidifying software engineering principles, clean code practices, and efficient problem-solving.
* **Data Structures:** Custom, optimized implementations of non-linear structures (Trees, Graphs, Heaps).
* **Design Patterns:** Application of SOLID principles and architectural patterns (Creational, Structural, Behavioral) in strongly-typed ecosystems to ensure scalable and maintainable software architecture.
